# ADR-0043: Selected GitHub source access through an external owner login

- Status: Accepted
- Date: 2026-09-21

## Context and task contract

M3-S13 follows integrated M3-S12 at `f0af6cc`. The owner selected an existing `gh` login and exact public/private repositories for a read-only local trial. The private selection and trial records stay outside Git. This decision implements FMU-FR-032 and FMU-E-020 under ADR-0003/0041, Security T-01/T-03/T-04/T-08 and the local private-source gate. It does not widen ADR-0039's public-history fallback.

The result is a separate owner CLI and Community source port for bounded discovery, source-file observations and commit metadata. No consumer MCP operation, Core policy, public wire schema, Store format, dependency or existing offline behavior changes. Persistent catalogs, automatic profile mutation, interpretation, account-wide enumeration, issues/PRs, writes, publication and hosted processing are outside this slice.

## Decision

- A closed versioned configuration selects an explicit authenticated account, opaque subject/repository identifiers, exact owner/name pairs and expected public/private visibility. Each repository separately permits metadata discovery, content and history. No selection is inferred from login permissions. Configuration contains no token or credential path.
- The external `gh` executable owns credential storage. A bounded `gh auth token --hostname github.com` subprocess supplies a transient token to a fixed Node HTTPS GET on `api.github.com:443`. The token is validated as a single ASCII value, used only in the TLS Authorization header, never returned or persisted, and acquired anew within each request deadline. Node rejects every non-200 response, including all redirects, without following Location; compressed responses are rejected. Prompts/pagers are disabled, no shell is used, credential stdout/stderr are limited to 8 KiB, and there are no retries or response caches. This deliberately replaces `gh api`, whose automatic redirects cannot enforce the selected-source boundary. Missing authentication is an ordinary content-free failure. The local runtime does not create credentials or request broader scopes; the owner should provision selected-repository read-only Metadata/Contents access outside Fork Me Up.
- Consent lasts at most 24 hours. A live owner-authority callback is checked before and after each request and before returning results, together with the runtime wall clock. Removing/changing the CLI configuration revokes that invocation at its next boundary. A changed account, repository identity or visibility rejects the run. Metadata discovery never fetches trees, blobs or history.
- Content permission includes resolving the default branch and its current commit/tree metadata; history permission additionally permits bounded ancestor metadata. After exact-name/visibility validation, object endpoints use the numeric repository ID so a rename/replacement cannot retarget content reads. Collection pins one commit and tree, validates returned object identities and verifies Git blob hashes. It reads only ordinary supported source files, skips links/submodules, secret/configuration and generated/vendor paths, and never executes or materializes repository content. Source text is transient input to byte/hash/language observations, never instructions or a model view. Commit identities become digests; messages are discarded. No observation establishes personal expertise or original authorship.
- Hard limits: 8 selected repositories, 64 requests, 1 MiB per response, 8 MiB response bytes, 60 seconds, concurrency 1, no retries, 4,096 tree entries per repository, 16 files per repository, 128 KiB per file, and 8 commits per repository. Configuration may lower limits. Truncated trees and budget exhaustion cannot masquerade as complete coverage. Even successful bounded collection is a sample, never complete knowledge of a repository or person.
- The internal immutable result is ephemeral, contains opaque references and normalized observations only, and is unavailable to consumer MCP. The CLI emits only fixed statuses and aggregate counts. No raw response, source, identity, repository name, private path or token is persisted or logged. Disconnect stops reads; releasing the result/process deletes this slice's memory. There is no source cache, Store mutation or backup in this slice. Any future persisted derivative requires M3-S14's retention/invalidation/deletion contract.
- Source consent grants no model disclosure. The authorized trial exposes only aggregate operation receipts; source text and private metadata remain local. Existing DCP permissions and the previous profile stay unchanged.

## Verification and security gate

Use synthetic ports and isolated subprocess fixtures for selection, separate scopes, account/visibility mismatch, grant expiry/revocation, unavailable credentials, malicious responses, object mismatch, byte/request/deadline limits, content-free errors and immutable results. Run focused checks and one final `npm run check`, including the unchanged offline/MCP/Store regressions. Complete an independent or documented second-responsible security review before live private collection. Do not claim live success before actual bounded reads pass; do not claim CI or integration from local checks.

The external login and GitHub are trusted transport/identity services, not source authority. Same-OS-user compromise remains outside local isolation. Renames, visibility changes and incomplete coverage fail closed or remain explicit; no absolute URL from a response is followed by the collector.

Authentication reference: [GitHub CLI token retrieval](https://cli.github.com/manual/gh_auth_token). API references: [repository metadata](https://docs.github.com/en/rest/repos/repos), [Git trees](https://docs.github.com/en/rest/git/trees), [Git blobs](https://docs.github.com/en/rest/git/blobs), [Git commits](https://docs.github.com/en/rest/git/commits). Read-only Metadata/Contents permissions are the intended credential ceiling; Fork Me Up cannot reduce a pre-existing broader external login.
